# CI and pre-commit

## Continuous Integration

For any Continuous Integration (CI), make sure to add things to
[config-ci-library][cicl], especially for things that are very likely reusable
for other repos.

Reference its actions and reusable workflows by full commit SHA with the tag in
a comment, never `@main`: they run with your repo's registry and release
credentials. Bump the SHA in a reviewed PR.

## Creating new repositories

When creating new repositories, copy the generated pre-commit config for your
language from [config-ci-library][cicl] (`pre-commit/configs/`) and use its
`general-check` reusable workflow and composite actions. Nothing syncs them
afterwards: when config-ci-library releases, replace the autogenerated section
by hand. If there is no config for your use case, add a component to
config-ci-library following the existing conventions.

[cicl]: https://github.com/pvarki/config-ci-library
